重构 UI —— 全程不用 !important

右边和左下各有一个实例。右边走的全是本页的覆盖规则，左下用 cssVars 走内联变量。

两层扩展点

① CSS 层：类名 + CSS 变量 + injectStyles: false

import { initChat, getChatStyles } from 'tdw-chat';

// 自己接管样式表（CSP 场景 / 想自己控制顺序时用）
const style = document.createElement('style');
style.textContent = getChatStyles();
document.head.prepend(style);

initChat({ injectStyles: false });

然后写普通 CSS 覆盖即可 —— 同权重、后写的赢：
.tdw-bubble { border-radius: 0; border-left: 3px solid currentColor; }

② cssVars：逐实例覆盖 token，内联 style，连权重都不用算

initChat({
  key: 'themed',
  position: 'bottom-left',
  cssVars: {
    '--tdw-color-primary': '#7c3aed',
    '--tdw-radius': '999px',
    '--tdw-launcher-size': '64px',
    '--tdw-panel-w': '340px',
  },
});

③ 逃生舱：getElement() 拿根节点，或者 renderMessage 完全自定义气泡内容

const chat = initChat();
chat.getElement();          // -> .tdw-root，随便你怎么折腾

initChat({
  renderMessage(message, { container }) {
    // 返回字符串 -> 走 textContent（安全）
    // 返回 Node   -> 原样塞进气泡
    return message.role === 'user' ? '🗣 ' + message.content : null;
  },
});

稳定契约（可以放心依赖）

类名：.tdw-root .tdw-launcher .tdw-panel .tdw-header .tdw-messages .tdw-message .tdw-bubble .tdw-time .tdw-composer .tdw-input .tdw-send .tdw-jump .tdw-error

语义属性：[data-tdw-part="bubble"] 比类名更稳，推荐优先用这个

状态：[data-tdw-state="open|closed"]、[data-tdw-theme="light|dark"]、 [data-tdw-position="bottom-right|…"]、[data-tdw-role="user|assistant|system"]

变量：--tdw-color-* --tdw-radius* --tdw-shadow --tdw-panel-w/h --tdw-offset-x/y --tdw-launcher-size --tdw-z-index --tdw-font-family --tdw-duration
